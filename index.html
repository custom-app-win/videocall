Cara Hosting Gratis di GitHub Pages

  1. Simpan file ini dengan nama index.html.
  2. Buat repositori baru (Public) di akun GitHub Anda.
  3. Upload file index.html ke repositori tersebut.
  4. Buka Settings → Pages, pilih Branch main, lalu klik Save.
  5. Gunakan URL HTTPS dari GitHub Pages untuk memulai panggilan video dari HP maupun Laptop.
